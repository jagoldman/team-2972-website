# Public website redesign demo

Open `index.html` in a browser. This is a local prototype, separate from the live website and the portal demo.

Approved visual direction (2026-11-11): Midnight & brass, dark mode only. The page ignores system appearance and previously saved theme choices. Theme controls have been removed. “Find your way in” panels remain borderless.

Core colors: background `#101827`, section `#152033`, panel `#1C293B`, text `#F3F5FA`, muted `#B4C0D1`, brass `#E6B849`.

All photos and fonts are included locally. No build step or server is needed. This preserves the existing artifact demo and its pages; it is not a production deployment.

Verified in headless Chrome: all 12 views at 320, 390 and 1440 px (36 layouts), no horizontal overflow or JavaScript errors. The site remains dark with a light OS preference and a saved light-mode choice. Visible text passed WCAG AA checks (minimum measured contrast 6.13:1). Desktop and phone screenshots were also inspected.
